# Між світлом — сайт фотостудії
Сторінки: index.html, portfolio.html, services.html, contacts.html (HTML + CSS + JS, без збирання).

## Публікація на GitHub Pages
1. Створіть репозиторій на github.com (наприклад `mizh-svitlom`), Public.
2. Завантажте весь вміст цієї папки в корінь репозиторію (Add file → Upload files; `index.html` має бути в корені).
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 хвилини сайт буде за адресою `https://ВАШ_НІК.github.io/mizh-svitlom/`.
